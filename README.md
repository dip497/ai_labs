# ai_labs

Small experiments and proofs of concept.

| Lab | What it explores |
|---|---|
| [agno-lazy-tools](agno-lazy-tools/) | Lazy (on-demand) tool loading for [Agno](https://github.com/agno-agi/agno) agents: tools enter the model's context only when a search finds them, within the same run. On OpenAI's Responses API it can use OpenAI's native tool search, which keeps the prompt cache intact. |
